## 2026-10-31

### Зачем не «поиск готовых GIF»
На Trigger много редкого/нового. Готовых гифок мало → путь через YouTube.

### Продуктовый поток
1. Трек с Trigger (юзер залогинен).
2. Несколько YouTube-вариантов в UI.
3. Выбор → скачивание во **временное** хранилище → удалить после.
4. Кроп → превью → upload на **свой** Giphy (логин на сайте, не API key у каждого).
5. Ссылка в чат Trigger.

### Скачивание YouTube
Сначала **без native helper**. Результат spike: см. `spike-youtube-no-helper.md`.

### Giphy
Логин на сайте — чтобы было ок обычным юзерам (~5 человек).

### Аудитория / раздача
~5 человек, ручная установка. Git: папка + `.zip` → Load unpacked.

### Репо
GitHub **public**: `trigger-track-gif` (owner: ratmansky).

### Порядок этапов
Сначала **A (показать трек)** — сверка глазами. Потом B → C → D → E.

### Этап A — откуда берём трек
Источник правды на проде: **`GET /api/current_song_details`** (без логина).  
DOM (player-bar / landing) — запасной и для сверки «как на странице».  
Локальный клон `Trigger re-diz` для расширения **не** используем.
