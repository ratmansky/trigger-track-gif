# Продуктовый план — Trigger Track GIF

Для людей, не для программистов. Что появляется на экране и зачем.

---

## Зачем вообще

На Trigger играют редкие/новые треки. Готовых гифок почти нет.  
Хочется за 30–60 секунд сделать короткую реакцию-гифку из клипа и кинуть в чат.

---

## Кто пользуется

~5 человек. Уже сидят на Trigger в Chrome.  
Ставят расширение вручную (файл → «загрузить»). Магазин Chrome не нужен.

---

## Как это ощущается (целевой сценарий)

1. Слушаешь Trigger, открыт чат.  
2. Жмёшь кнопку расширения (или кнопку рядом с «сейчас играет»).  
3. Видишь **3–6 роликов** с YouTube под этот трек (обложка + название).  
4. Выбираешь один.  
5. Открывается простой экран **кропа**: полоска времени, «отсюда / досюда» (цель — ~2–6 сек).  
6. Жмёшь «Сделать гифку» → смотришь превью.  
7. Если ок → «Залить на Giphy» (ты уже залогинен на giphy.com).  
8. Ссылка сама попадает в поле чата Trigger (можно сразу отправить).

Временный ролик после заливки/отмены **стирается** — не засоряет комп.

---

## Этапы (что пилим по порядку)

Каждый этап можно потрогать руками. Не «всё сразу».

### Этап A — «Видим трек»
**Продукт:** расширение показывает: *сейчас играет Artist — Title*.  
**Проверка:** открыл Trigger → в расширении правильное имя трека → сменилась песня → имя обновилось.

### Этап B — «Выбор ролика»
**Продукт:** по треку список YouTube-вариантов, клик = «этот».  
**Проверка:** на знакомом хите находятся норм клипы; на редком треке — хоть что-то / честное «ничего не нашли».

### Этап C — «Достали кусок видео» *(сейчас следующий тех.spike / PoC)*
**Продукт:** после выбора ролика через минуту есть **короткий файл**, из которого можно кропать (ещё без красивого UI).  
**Проверка:** выбрал ролик → файл появился → его можно открыть/проиграть локально.  
**Риск:** YouTube может ломать этот путь — тогда вернёмся к плану B (маленькая программа на компе).

### Этап D — «Кроп и превью»
**Продукт:** ползунки начала/конца, превью гифки/короткого клипа.  
**Проверка:** отрезал 3 секунды припева → превью понятное, не чёрный квадрат.

### Этап E — «На Giphy и в чат»
**Продукт:** «Залить» → ссылка в чат Trigger.  
**Проверка:** гифка открывается у друзей в чате (или хотя бы ссылка кликабельна).  
**Риск:** «логин на Giphy как на сайте» может оказаться сложнее, чем кажется — тогда запасной путь: API ключ один на всех / ручное «скопировать ссылку».

## Что сознательно не делаем в v1

- Магазин Chrome  
- Красивый брендинг на уровне продукта  
- Автозалив без превью (всегда смотрим глазами)  
- Длинные клипы (>~10 сек)  
- Мобильный Chrome  
- «Умный» автокроп припева (потом, если захочется)

---

## Критерий «можно раздать пятёрке»

Друг без инструкций на полчаса:

1. Поставил расширение из zip  
2. На Trigger нажал кнопку  
3. Выбрал ролик → кропнул → залил  
4. В чате появилась гифка/ссылка  

Если на шаге «достали видео» часто ломается — **не раздаём**, чиним или helper.
